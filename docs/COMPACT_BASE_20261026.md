# 当前最精炼开发版本的冻结决定

2026-10-26：默认底座固定为 **B0**，即参考来源内选择的RNA Ridge，加固定系数0.5的物理空间校正。最低平均RMSE的神经候选`own_mlp`保留为对照。这里的“精炼默认”和“最低均值”使用不同、预先登记的标准，不能将B0写成所有候选中数值最优。

| 候选 | 三种子来源宏RMSE | 相对B0的RMSE差 | 改善来源数 |

| own_mlp | **0.793147029** | -0.001321979 | 3/6 |
| neighbor_mlp | 0.794450080 | -0.000018929 | 3/6 |

预登记规则是在最低均值加一倍优化标准误的范围内，按B0、own_mlp、neighbor_mlp顺序选择最简单模型。own_mlp的优化标准误为0.001645238，入选上限为0.794792267，三者均在范围内，因此选择B0。它是精简启发式，不是等效性检验，也不是供体置信区间。own_mlp的平均相对收益约0.166%，不能据此宣称神经残差没有作用。

六个保守来源组包含十份切片；来源组并不全部等于已确认独立供体。三种优化种子没有增加独立供体数量。以上数据均已用于开发。

确认共36个外层候选任务，其中24个新任务及12个复用的A40 seed2025任务全部独立核验。报告还核对每个匹配任务的31次实际嵌套拟合输入。冻结脚本独立重算每个种子和来源的宏指标后再检查预登记决定，没有改动原有选择规则或舍弃负例。

当前17个核心Python文件提供训练、来源内选择、续训、独立导出及RNA-only预测；B0路径无需PyTorch。两种可选神经头通过CPU完整62次嵌套拟合与旧实现逐值一致检查、受控确定性CUDA完整拟合逐值一致检查，以及真实4164×31独立wheel部署核对。CUDA软件对照使用合成输入和明确的确定性设置，不证明默认非确定性GPU训练逐位可复现，也不提供生物学效果证据。

机器可读冻结身份见[compact_base_freeze.json](compact_base_freeze.json)，当前状态见[core_readiness.json](core_readiness.json)，CUDA证明见[cuda_training_validation.json](cuda_training_validation.json)。原始确认报告保存在研究checkout的`runs/stprotein2_compact_confirmation_20261025_v1/`；本次冻结保存于本checkout的`runs/compact_base_release_20261026_v1/`。
