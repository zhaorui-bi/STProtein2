**Hierarchical reference initialization candidate, 2026-10-13.**

This separate package implements the v2.0 design's source → slice → unique-spot initialization. It does not change any frozen historical router, model, Teacher experiment, or training namespace. It is not yet integrated into a full nested training CLI and has no protein-accuracy result.

Each allowed source receives the same sample count B, capped by the smallest total source capacity and the requested per-source limit. Within a source, deterministic round-robin water filling gives slices equal quotas until their capacities bind; remaining quota is redistributed among slices with remaining capacity. Slice order is canonical and rotated by the recorded seed. Barcodes are sorted before a source/slice-specific seeded draw without replacement. Record all sampled barcodes, actual quotas, capacities, reference names/groups and a content hash. Input view and row permutations must preserve selected biological IDs.

The new router retains the existing reference PCA, normalization, KMeans initialization and ten spherical refinements. Its PCA arrays are made contiguous before the first transform: an initial exact serialization test exposed 1.49e-8 differences from a noncontiguous PCA component layout being changed by joblib. The original failed log is retained, the representation values are not changed, and the exact round-trip assertion is retained after canonicalization. This layout rule is part of the new candidate, not a retroactive alteration of old routers.

Prototype initialization receives RNAView objects and explicit allowed names, samples unique nodes, initializes state first, then recomputes niche using initialized state codes. Only the two code parameters change; the Student train/eval mode is restored. The caller copies Student to Teacher afterward. The helper neither reads measured protein nor independently reclusters Teacher. Insufficient unique samples and graph/name mismatches fail before changing codes.

Required targeted tests cover unequal slice capacities, exact source quotas, no duplicated spots, view/row order invariance, accidental held-query inclusion, router save/load and held-query prediction, state-before-niche initialization, unchanged non-code weights, Teacher slot identity and insufficient-sample rejection. The first three targeted tests pass after the disclosed PCA layout fix.

The real RNA audit uses the frozen Breast-outer reference transformation from the existing common-input experiment, fits the new router on the nine allowed reference slices, and applies it to Breast RNA after freezing. It records real quota redistribution and exact joblib prediction round-trip, while forbidding ADT reads. It does not train a protein predictor or select hyperparameters from the held source. Subsequent matched model training must register this initialization as its own candidate and preserve reference-only nested selection.
