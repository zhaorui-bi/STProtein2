# 六来源竞争方法：相同参考与预处理的独立轨道

本协议将已有MLP、官方TabM、RNA0、DPAS-Graph和DGAT适配到扩充的十切片/六保守来源。原七切片结果继续保留，不能与本轨道的宏指标混排。新增编排位于`stprotein2_extended_baselines`，旧网络、损失、优化器、采样和轮数选择函数不修改。

每个外层排除整个查询来源及其全部切片。其余五来源逐一内层留出，重新使用精确对应训练子集的HVG/scaler；这些变换直接来自已核验的独立anchor缓存，不用查询RNA选基因。五个内层各在80轮上限、每4轮验证、patience6下选择轮数，取中位数后在五来源重训。所有模型为seed2025、4000基因、同一有符号31抗体centered-log目标；每轮每来源均匀抽一张切片，无增强。六外层每方法36次训练；STProtein2另有门控的嵌套成本，需分别计入总fits和资源。

普通MLP为既有ProteinMLP，RNA0为既有ProteinAutoencoder；官方TabM保持默认32成员/512宽/3块。DPAS保留公开模型和原有三优化器/预测加RNA重建目标；DGAT保留其原生组件、五项损失和单设备梯度语义。统一预处理和参考内部checkpoint选择意味着这是common-input比较，不宣称复现论文分数。QC/availability输入是否使用属于架构差异，另做STProtein2入口消融。不同方法超参未经完整公平搜索，本轮同80轮上限不等于相同优化充分性。

新的外层预测程序不打开或哈希查询ADT，禁止通过测量读取接口访问其蛋白。输入和来源、每层预处理、原模型源码、实际选定轮数、模型/预测哈希均保存。已完成缓存需重新核验；改变查询蛋白不改变预测。评分使用独立命令，发生在预测文件冻结之后。输出`base`明确为同参考冻结RNA anchor，方便相同查询的配对比较。

新增控制需验证实际多来源训练、完整来源排除、与旧训练函数的逐权重/逐预测一致、同组多个查询的完整覆盖、删除/改变查询ADT后的可预测性、实际中断恢复、已完成模型或输入损坏拒绝。合成低维测试只证明编排正确，不能替代默认大模型真实运行。

执行顺序：CPU先完成MLP；小显存TabM、RNA0可在共享GPU有足够余量时串行推进，保持当前C0/CF0不变。DPAS和DGAT等待当前外层矩阵结束后再启动。不同进程共享硬件的时间只作执行记录，不用于独占条件速度排名。GPU内存门槛是准入启发式，不是资源保证；仅确认新子进程终止且日志包含CUDA OOM后允许同配置恢复。

主指标为先切片后来源等权的RMSE，另报逐蛋白、PCC/Spearman、MAE、最差来源与空间误差。只允许同查询覆盖的配对比较；全部六来源完成前不按局部宏分数排全局名次。该轨道已用于开发，尚不能建立独立SOTA；进一步需要适用竞争者、多种子、独立配对和生物学验证。
