# Layout-independent preprocessing identity

The first recovered real diagnostic rejected a valid saved RNA router: its fitted PCA components retained a noncontiguous layout before serialization. Loading the same numerical array changed the layout and the opaque `joblib.hash`. An independent RNA-only reconstruction reproduced the original pre-save hash, the post-save hash, and all saved PCA parameters/centers exactly. Evidence: [round-trip audit](audits/teacher_router_roundtrip_20261013.json).

`stprotein2_teacher_ablation_v2` preserves the Student, Teacher algorithms, initialization, loss, optimizer and data rules of the original Teacher package. It changes identity serialization only: NumPy arrays are identified by dtype, shape and contiguous element bytes; sequences, dictionary keys, estimator class and complete fitted state remain included. Unsupported objects/object arrays fail explicitly; no numerical values or features are omitted to bypass identity checks. Nonfinite scalar identity values are rejected. Artifact files retain strict SHA256 checks in addition to content identities.

The new trainer uses this canonical router identity in its manifest. The new nested runner compares canonical saved/rebuilt preprocessing, writes a marker binding preprocessing file SHA256, and includes all such artifacts in the outer prediction completion marker. A dtype, feature order, fitted parameter, source name or configuration change is still rejected. Model math and numerical tolerance are unchanged.

Old model packages and existing runs remain frozen. The successful original C0/EMA fit may be reused in the recovered short diagnostic after checking all original fit hashes, the independent round-trip evidence and the saved preprocessing identity. This is explicitly recorded as a version1 fit; new short/long fits use version2 identity handling. The original two stopped report attempts remain available, and neither is represented as a successful complete matrix.

Required checks: content identity survives actual noncontiguous-array serialization; genuine value changes are rejected; completed training can be reused with such a router; EMA updates/predictions remain exactly equal to the unchanged version1 trainer in deterministic tests; new nested completion markers bind preprocessing. Real historical comparisons retain the disclosed FP32 tolerance from the [numerical recovery protocol](TEACHER_DIAGNOSTIC_RECOVERY_20261013.md).
