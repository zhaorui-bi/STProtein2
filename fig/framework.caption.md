# STProtein2 framework figure

Selected figure: `framework.png`.

## English figure legend

**Figure 1 | STProtein2 predicts spatial protein expression using a frozen spatial anchor and dual-level prototype-guided residual corrections.** **a**, Query RNA counts, gene availability and RNA quality-control features are processed using reference-fitted transformations. An independently fitted, frozen Ridge model provides the RNA anchor, augmented by a fixed centered spatial basis with coefficient α = 0.5. An eight-member shared RNA ensemble learns spot representations. State and local residuals are added to the spatial anchor through separate binary switches for each protein. Coordinates define the physical neighbor graph G; circular G badges identify graph-dependent modules. The illustrated configuration predicts 31 measured antibody targets in centered-log expression space; the spatial maps are schematic. **b**, Soft assignments to 32 state prototypes and 16 niche prototypes produce expression-state and neighborhood-context memories. The state residual compares readouts with state memory and zero memory, followed by a learned RNA-QC gate. Niche memory combines the spot representation, neighboring representations, neighboring state assignments and RNA QC. **c**, Four cooperative sheaf neural network experts produce graph-context-versus-self-only contrasts. Mixing weights depend on spot, state and niche context together with protein embeddings. The weighted expert residual and neighborhood-versus-own-niche readout contrast are summed, QC-gated and centered across non-isolated spots. Isolated spots receive zero local correction. **d**, Paired reference ADT supervises training and held-out evaluation. Fold-specific reference refits support per-protein selection among base, state, local and combined predictions. Residuals are enabled only when validation has at least four units, mean relative MSE gain of at least 1%, and gains in at least 60% of units. Query ADT is used only for scoring. The displayed configuration uses C0 in-fit residual targets, no EMA teacher and full-graph execution.

## 中文图注

**图 1｜STProtein2：冻结空间锚点与双层原型引导的残差校正。** **a**，模型以查询切片的 RNA、基因可用性、RNA QC 和空间坐标为输入。参考数据拟合的 Ridge 锚点与固定空间基底构成基础预测；8 成员 RNA 集成学习表征，状态和局部残差通过逐蛋白开关加入基础预测。圆形 G 标记表示模块使用空间邻居图。**b**，32 个状态原型和 16 个生态位原型分别提取表达状态与邻域记忆；状态分支比较有记忆与零记忆的读出。**c**，4 个协同 sheaf 专家产生空间图相对自环图的差异，按蛋白条件化权重融合，再加入生态位差异读出，经 QC 门控和非孤立点中心化得到局部残差。**d**，参考 ADT 用于训练和留出验证，通过参考折内重拟合，在基础、状态、局部及联合预测之间逐蛋白选择。门控规则为至少 4 个验证单元、平均相对 MSE 改善至少 1%、至少 60% 的单元改善。查询 ADT 仅用于评分。图对应当前 C0、无 EMA Teacher、全图运行配置。
